# BanglaQuizMaster

Interactive Bangla quiz web application with real-time answer validation, category-based questions, and score tracking.

## Features

- Bangla language quiz interface
- Multiple-choice questions with instant feedback
- Score calculation and results display
- Category-based question sets
- Clean responsive UI

## Project Structure

```
index.html     - Quiz interface
css/           - Styling
js/            - Quiz logic and question data
```
